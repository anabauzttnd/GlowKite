# GlowKite

GlowKite is a cloud-based, real-time data processing engine that leverages auto-scaling infrastructure for dynamic analytics.

With GlowKite, you get a lightweight tool that stays out of your way.

**What you get**

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/GlowKite.git`
2. `cd GlowKite`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
